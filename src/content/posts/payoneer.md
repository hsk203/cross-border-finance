Payoneer（派安盈）是跨境电商卖家、自由职业者最常用的收款工具之一：亚马逊、Upwork、Fiverr、Airbnb 等平台都支持用 Payoneer 收款。本文讲清楚 Payoneer 的注册流程、收款手续费、提现到国内银行卡的方法和费用。

> 本文仅为信息整理，不构成任何金融建议。费率会随时调整，使用前请以 Payoneer 官网的最新信息为准。

## Payoneer 是什么

Payoneer 是一家美国跨境支付公司，成立于 2005 年，在纳斯达克上市。它的核心功能是：帮你收海外平台的款，再提现到你的国内银行卡。

- **收款**：亚马逊、Upwork、Fiverr、Airbnb、Wish 等平台打款到你的 Payoneer 账户。
- **多币种**：支持美元、欧元、英镑、日元等多种货币收款。
- **提现**：把 Payoneer 余额提现到国内银行卡（人民币）。

## 注册流程

1. 在 Payoneer 官网注册个人或企业账户。
2. 填写个人信息、联系方式、银行账户信息。
3. 上传身份证件（身份证或护照）进行身份验证。
4. 等待审核，一般 1–3 个工作日。
5. 审核通过后，获得美国、欧洲等地的本地收款账户（虚拟银行账号）。

## 收款手续费

| 收款方式               | 手续费                         |
| ---------------------- | ------------------------------ |
| 从 Payoneer 客户收款   | 免费（同一 Payoneer 账户之间） |
| 从平台收款（亚马逊等） | 免费或 1% 以下                 |
| 信用卡付款             | 3%                             |
| 美元电汇               | 1%                             |

## 提现到国内银行卡

- **提现费率**：约 1.2%（提现到人民币银行卡）。
- **到账时间**：通常 1–3 个工作日。
- **最低提现**：50 美元。
- **汇率**：按提现时的市场汇率换算成人民币。

## Payoneer vs Wise

| 对比项   | Payoneer                   | Wise                       |
| -------- | -------------------------- | -------------------------- |
| 主要用途 | 收平台款（亚马逊、Upwork） | 个人汇款、换汇             |
| 收款     | 免费（平台打款）           | 免费                       |
| 提现费率 | 约 1.2%                    | 约 0.6%–1%                 |
| 适合人群 | 跨境电商卖家、自由职业者   | 个人汇款、留学、给家人汇钱 |

如果你是亚马逊卖家或自由职业者，用 Payoneer 收平台款；如果你是个人汇款，用 Wise 更便宜。

## 常见问题

**Payoneer 提现要多久？** 通常 1–3 个工作日到账。

**Payoneer 有年费吗？** 账户本身没有年费，但如果 12 个月没有任何交易，可能会收取账户管理费。

**Payoneer 能收人民币吗？** Payoneer 主要收外币（美元、欧元等），提现时换成人民币到国内银行卡。
